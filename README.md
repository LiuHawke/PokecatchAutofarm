# PokecatchAutofarm

Poke'Catch 网页游戏挂机助手：Chrome / Edge（MV3）浏览器扩展，支持战斗沙盒重放配队、主线自动推进、精确喂糖、培育屋托管、存档备份，附游戏机制攻略。

当前版本：**1.1.0**

## 功能

- **配队**：用游戏原版战斗逻辑在沙盒里重放，覆盖路上训练家、招式禁用和状态抗性，后台轻量重算不卡顿
- **联盟**：按顺序整轮连打（含精英阶级），一次算完整个周目
- **禁招**：按对战模拟逐只搜索，一键替您点禁用，可撤销
- **主线推进**：感知等级上限，自动推进章节，换地区时自动清理
- **养成**：经验糖精确喂养不溢出、按需买糖、培育屋和树果托管
- **活动与统计**：实战伤害统计按章节分段、带可拖动悬浮窗，属性克制面与补位推荐，方块首领/地下通道选队推荐，每日每周玩法提醒
- **稳定性**：一键三档预设、后台保活、停滞自愈、存档备份、自检

## 构建与安装

需要 Node.js。

```bash
node tools/build.js
```

构建产物在 `dist/ext-1.0.0/`（同时生成同名 zip）。在 Chrome / Edge 打开 `chrome://extensions`，开启开发者模式，选择“加载已解压的扩展程序”，指向 `dist/ext-1.0.0` 即可。

## 目录结构

| 目录 | 说明 |
|---|---|
| `src/` | 按数字前缀排序的功能模块，构建时拼成一个闭包 |
| `ext/` | 扩展的 manifest、bridge、popup、app-wrap |
| `data/` | 构建时注入的内置数据（章节、进化、战斗招式表） |
| `tools/` | 构建、扩展检查、对战模拟校验、数据生成脚本 |
| `guide/` | 根据游戏源码整理的攻略与 84 章逐章数据 |

## 数据说明

`data/*.json` 已随仓库提供，日常构建不需要重新生成。`tools/gen-data.js` 用于基于新版游戏重新生成这些数据，它依赖作者本地的游戏数据提取目录（不随仓库公开），普通使用者无需关心。
