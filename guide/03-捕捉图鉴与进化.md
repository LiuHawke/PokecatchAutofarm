## 1. 遭遇怎么生成

### 1.1 章节、步骤与节点

- 每个章节（`STORY.CHAPTERS`，共 84 章）由若干步骤（`steps`）组成；`kind:"route"` 的步骤会按 `wild` 生成对应数量的**野生节点**，按 `trainers` 插入训练家节点（`pa()`）。
- 有 `night:true`/`day:true` 的道路步骤只在夜晚/白天生成（例如合众「Forêt Blanche（白森林）」只在白天出现）。
- 有 `tide` 的步骤（丰缘浅滩洞穴）按潮汐（`STORY.TIDES`）出现。
- 章节每次重新开始（包括重复刷章节）都会重新生成节点。游走传说也在这一步分配到某个野生节点上（见 §5.1）。

### 1.2 一个野生节点出什么（`fa()`/`Me()`，按优先级）

1. **游走传说**：节点被标记了 `roamer`，而且这只还没被抓 → 必定遇到它，等级 `max(100, 你最高等级)`，也就是 100（`Roaming.level()`）。
2. **合众「现象」**：合众章节里每个道路步骤有 5%~10% 概率把其中一个野生节点变成现象节点（摇草丛/尘烟/影子/水波），现象节点又有 20% 变成道具（`PHENOMENA`）。
3. **幻之宝可梦**：非活动、非"way"节点有 `MEW_CHANCE = 0.03%` 换成本地区幻之宝可梦（关都梦幻 Lv30、城都时拉比 Lv40、丰缘基拉祈、神奥谢米、合众比克提尼，都是 Lv50 基准再按章节缩放）（`STORY.REGIONS[].mythical`）。
4. **普通池**：
   - 如果 `HABITATS["步骤名|区域1+区域2"]` 存在（225 个野生步骤里有 223 个）→ 用 HABITATS 权重；
   - 否则用 `ENCOUNTERS` 原作数据 + `RARE_WILD` + `CONDITIONAL_WILD`（只有合众「Pont Yoneuve（浮桥）」「Forêt Blanche」两个步骤走这条路，再加上找不到数据时的整章兜底 `Ue()`）。
5. **进化形态抽签**：抽中物种后，按野生等级把它能到达的等级进化链列出来（最多 3 段），按 `STAGE_ODDS = [70, 25, 5]` 抽取第几段（`ke()`）。例如野生 Lv25 的波波，大约 74% 是波波、26% 是比比鸟。进化形态的等级 +2/段（`WILD_EVOLVED_LEVELS=2`）。
6. 等级不会超过当前等级上限（`capFor()`）。夜晚的"昼行性"宝可梦（由 `TIME_WEIGHTS` 判定，见 §3.4）有 35% 概率一出场就睡着（`NIGHT_SLEEP=0.35`）。

### 1.3 HABITATS 的条件规则（`Me()`）

每个 HABITATS 条目形如 `{base:{id:权重}, night:{…}, rain:{…}, storm:{…}, …}`：

| 情况 | 效果 |
|---|---|
| 物种在 `base` 里，且条件表里也有它 | 条件激活时权重改为条件表的值；值为 0 = 该条件下消失 |
| 物种不在 `base`（或 base 权重为 0），只在条件表里 | **只在该条件激活时出现** |
| `quest:X` 键 | 列出的物种在完成剧情 X（拿到 `adv.gifts[X]`）之前完全不出现 |
| `lv` 键 | 该物种等级额外加成 |

可用条件键（统计全部 227 个 HABITATS 得到）：`night`(133)、`rain`(108)、`storm`(86)、`sun`(31)、`snow`(19)、`day`(14)、`fog`(7)、`sand`(5)、`blizzard`(5)、`ash`(2)、季节 `spring/summer/autumn/winter`(4~6)，以及 9 个 `quest:*`。

- **时间段**（`DAYTIME.PHASES`，按设备本地时钟）：8:00–10:00 清晨（`morning`，同时算作 `day`），10:00–20:00 白天，20:00–次日 8:00 夜晚。室内/洞穴节点不受时间影响。
- **季节**：按日期每 3 天轮换一次，春→夏→秋→冬（`DAYTIME.season()`）。
- **天气**：每整点一个时段（`WEATHER.SLOT_MS = 1 小时`），用"章节号+时段"做哈希决定，**是确定的、可以预测的**；大约 54% 的时段有天气（`CHANCE=0.54`）。每种地形可能出现的天气见 `WEATHER.CLIMATES`；关都、城都不会随机出现大晴天（`REGION_OFF`），晴天类天气夜晚不出现。天气优先级：节点固定天气 > 章节固定天气 > **游走传说带来的天气** > 随机。
- HABITATS 路径**不再**额外乘 `WEATHER.TYPES[].encounters` 的属性倍率（那个倍率只在 ENCOUNTERS 路径的 `W()` 里用）。

## 2. 捕捉

### 2.1 捕获概率（`Ks()` + `Un()`）

```
p = battle.rate 存在 ? battle.rate / 255
  : 传说或幻之   ? 3 / 255
  : captureRate × 0.6 / 255
最终 p = min(0.6 × 树果倍率, p × 树果倍率)
```

- 判定方式：连续 4 次"晃动"、每次成功率 `p^0.25`，4 次都过才成功 → 总成功率正好是 `p`。晃几下只是表现。
- **球不影响概率**。显示用哪种球由稀有度决定（`TIERS[].ball`），纯外观。
- 树果（持续 60 分钟，同种可叠到 8 小时，`BUFF_MIN=60`、`BUFF_STACK=8`）：蔓莓果（Baie Framby）×1.25，金色蔓莓果 ×1.5；上限也一起放大（最高 0.9）。对传说、游走、团体战同样有效。
- PC 没有容量限制（`storageFull()` 恒为 false），所以不会因为"PC 满了"跳过捕捉。

### 2.2 稀有度（`tierOf()` → `CONFIG.TIERS`）

| 稀有度 | 判定 | 显示球 | 售价 `sell` |
|---|---|---|---|
| 普通 common | 捕获度 > 120 | 精灵球 | 40 |
| 少见 uncommon | 捕获度 ≤ 120 | 超级球 | 120 |
| 稀有 rare | 捕获度 ≤ 45 | 高级球 | 350 |
| 传说 legendary | `legendary`/`mythical` | 高级球 | 5000 |
| 唯一 unique | `unique`（如活动皮卡丘 Pika'Squette #90025） | 大师球 | 0 |

修正：进化形态至少比前一段高（二段进化至少"少见"，三段至少"稀有"，最多到稀有）；种族值总和 ≥450 至少"少见"、≥500 至少"稀有"；`TIER_MIN` 强制：溜溜糖球、丑丑鱼 ≥ 少见；美纳斯、花岩怪、螺钉地鼠、差不多娃娃、鸭宝宝、电飞鼠、保姆曼波、牙牙 = 稀有。`TIERS[].level` 字段的用途**待确认**（没找到捕捉相关引用）。

稀有度会影响：蕉香果加成（只对"稀有"生效）、伙伴每升一次需要的击倒数（`BUDDY_KOS`）、培育屋糖果需求（`PENSION.CANDY_MIN`）。

### 2.3 捕捉设置 `adv.capture`

| 字段 | 取值 | 效果（`Rn()`） |
|---|---|---|
| `on` | true / false | false 时完全不扔球，重复物种也不会转成糖果 |
| `shiny` | true / false | true：闪光个体无论如何都扔球 |
| `target` | `'new'`（默认）/ `'missing'` | 两者效果相同：只对"本地区还没拥有"或"家族还需要这只"的个体扔球 |
| | 其他任意值（如 `'all'`） | 所有非重复个体都扔球；和 `'new'` 的实际差别只在**已经拥有的传说**（`'new'` 下不再扔） |

**重要**：`E()` 每次被调用都会执行 `Object.assign(p.capture, {on:true, target:'new', shiny:true})`，也就是说**这套设置在当前版本被锁死**，界面上也没有修改入口（`zh-ui` 里找不到对应文字）。改存档也会被立即改回。所以实际规则就是：**新物种必扔、闪光必扔、重复物种必收糖、已拥有的传说不再扔**。

### 2.4 "每个物种只能有一只"的精确规则（`isDup()`=`ps`、`fitsFamily()`=`jn`）

一只新抓的个体被判定为"重复"，需要同时满足：

1. 不是传说/幻之（传说永远不算重复，但在 `target:'new'` 下已拥有的不会再扔球）；
2. 同一"地区组"、同为闪光或同为非闪光的收藏里**已有同种**；
3. 家族不需要它（`Vs()` 计算家族要几只才能进化出全部分支，例如伊布有 7 个分支，按 `Vs()` 的逻辑会保留足够做出各分支的伊布，而不是转糖；具体数量**待实机确认**）。
   - 卡片上可以打开「保留重复的 X」（`keepDup`），之后该家族的重复个体都会留下。

**闪光和普通分开算**：已有普通妙蛙种子，再抓到闪光妙蛙种子是新收藏。
**地区组**：平时所有地区共用一个收藏（组 `all`）；正在攻略一个新地区、还没打过它的联盟时（`S.link`），新地区一侧单独成组（界面文字「Jusqu'à la Ligue de {region}, chaque côté a ses Pokémon et ses ₽」）。

### 2.5 重复捕获的收益（`zn()` / `Fs()`）

| 情况 | 收益 |
|---|---|
| 新个体等级 > 你同种（同闪光状态）那只，且那只没到等级上限 | 你原来那只**直接升到新个体的等级**（「重复：你的 X 从 a 级升到了 b 级」） |
| 否则 | 家族里每只没到上限的成员各得 `round(Xa(自身等级) × 3) × DUPLICATE_CANDIES(1) ÷ 家族成员数` 经验 |
| 家族全员到上限 | 什么都不给（「它的家族已达等级上限」） |

按公式推算（关都，`XP_LEVEL_GROWTH=1.0361`，单成员家族）：Lv≤10 约等于 1 整级，Lv20 ≈ 0.70 级，Lv30 ≈ 0.49 级，Lv50 ≈ 0.24 级；城都/丰缘再 ÷1.25，神奥/合众 ÷1.35（`REGION_XP`）。家族成员越多，每只分得越少。这是推算值，**待实机确认**。

重复个体是**免扔球、100% 收下**的（`prob:1`），所以在已经抓满的地图上挂机，每只被打倒的野生都会变成家族经验。

## 3. 闪光、稀有与条件出现

### 3.1 闪光

| 途径 | 概率 | 来源 |
|---|---|---|
| 野生基础 | 1/2048 ≈ 0.049% | `SHINY_RATE` |
| 当前地区图鉴全满（每种都"抓到过"，包括传说和幻之） | ×2 → 1/1024 | `shinyDone()`、更新日志 |
| 星桃果（Baie Frista，`starf-berry`） | ×2，可与上一条叠加 → 1/512 | `BUFF_BERRIES` |
| 活动 / 传说区域 / 游走 | 不会随机闪光 | 野生生成 `kt = ja\|\|event\|\|zone ? false : …` |
| 剧情固定闪光 | 愤怒之湖红色暴鲤龙 | `static.shiny` |
| 培育屋 | 基础 1/512，父母有闪光 1/16，蓝橘果（Baie Belue）×2 等，详见培育屋一章 | `PENSION.SHINY_*` |
| 异色团体战 | 每天每地区一只闪光首领，每次打倒有一定概率捕获（界面写 1%），详见团体战一章 | `zh-ui`、`WORLDBOSS/RAID` |

闪光个体六项能力 ×1.1（`SHINY_STAT_BONUS`）。捕捉设置 `shiny:true` 被锁定，所以遇到闪光一定会扔球（概率仍按 §2.1，不保底）。

### 3.2 `RARE_WILD` / `RARE_SHARE` / `CONDITIONAL_WILD` 的实际作用

### 4.2 进化什么时候发生

- **队伍里的宝可梦**升级时，若满足等级进化 → 自动播放进化（单一路线）或弹出选择（多路线）。
- **PC 里的宝可梦**（例如靠重复捕获的家族经验升级）不会自动进化：在 PC 界面用「Faire évoluer N Pokémon ?（让 N 只宝可梦进化？）」批量进化，或在卡片上点进化。
- 道具进化只在卡片上手动用道具。
- **会被阻止的情况**（`evoBlocked()`=`qe`）：
  - 宝可梦在地下城升过"段位"（`rank>0`）后永远不再进化（「升过段位的宝可梦不会再进化」）；
  - 同组、同闪光状态里**已经有进化后的物种**，而且这次进化会让家族出现多余个体 → 按钮变灰，提示「已拥有 X」。
- 野生宝可梦的进化形态由 §1.2 第 5 步的等级抽签决定，与玩家无关。

## 5. 传说与游走

### 5.1 游走传说（`Roaming` + `CONFIG.ROAMING`）

| 组 | 成员 | 解锁徽章（打败该地区冠军） | 活动地区 | 自带天气 |
|---|---|---|---|---|
| 1 | 雷公 / 炎帝 / 水君 | 城都冠军（「Maître Johto」） | 城都 | 雷雨 / 大晴天 / 雨 |
| 2 | 拉帝亚斯 / 拉帝欧斯 | 丰缘冠军 | 丰缘 | 微风 / 微风 |
| 3 | 艾姆利多（#481） | 神奥冠军 | 神奥 | 无 |
| 4 | 龙卷云 / 雷电云 | 合众冠军 | 合众 | 狂风 / 雷雨 |

规则：

1. **可停留的章节**：属于该组地区、章节号 ≤ 已解锁进度、地区已解锁、在该地区联盟章节之前、并且有室外有野生的道路步骤（`Ve()`）。同组几只不会待在同一章。
2. **停留时间**：`STAY_MIN = 15` 分钟，到点后换到另一个可停留章节（只要有 2 个以上选择就不会原地不动）；吃了苹野果（Baie Pommo，`rowap-berry`）×2 → 30 分钟。时间用游戏时钟（`Game.time()`）计算；离线期间是否照常换位**待确认**。
3. **遭遇**：你开始（或重开）它所在的章节时，章节里随机一个室外野生节点被标记为它 → 这一轮**必定遇到 1 次**。联盟章节不会出现。
4. **战斗**：等级 100，血量 ×4、攻击 ×0.6（`LEGEND_ZONE.ROAM_HP/ROAM_POWER`），带怒气条。
5. **捕捉**：打倒后只扔 1 个球：背包里有大师球就**自动消耗一个大师球、100% 捕获**；否则 4% × 蔓莓果倍率。失败它继续游走。

7. 抓到后可在传说区域列表里以 `roam` 区域形式出现（`ROAM_ZONES`，只用于精英模式重战）。

期望：不用大师球时平均 25 次遭遇（= 25 轮章节）抓到一只；金色蔓莓果下约 17 次。

以下每条写成"条件 → 动作"。`S` 表示存档对象 `a.Game.S`，`adv = S.adv`。

**捕捉**

1. 不要尝试改 `adv.capture`：任何 `E()` 调用都会把它改回 `{on:true,target:'new',shiny:true}`。脚本只需假设"新物种、闪光自动扔球，重复物种自动转经验"。
2. 选刷怪地点时，用 `p = min(0.6·m, captureRate·0.6/255·m)`（m = 当前捕捉树果倍率）估算；若目标物种 `captureRate ≤ 45`（p ≤ 10.6%）且背包有金色蔓莓果 → 先吃金色蔓莓果（×1.5，60 分钟，可叠到 8 小时）再刷。
3. 目标是传说区域/游走 → 必吃金色蔓莓果：传说 1.18% → 1.76%，游走 4% → 6%。
4. 想给某个家族升级 → 去一个该家族常驻占比高、且野生等级 > 你那只等级的地图挂机：每次遇到都会 100% "收下"，高等级个体直接把你那只拉到同等级（`zn()`）。判断：`野生max等级 > 你的等级 且 你的等级 < 等级上限`。
5. PC 无上限，不需要清理 PC 来保证捕捉。

**稀有/条件宝可梦**

6. 每到整点重新读取 `a.WEATHER.current(node)` 和 `a.WEATHER.forecast(node)`（确定性、可预测）。目标物种在 §3.3 表中的条件为"雨/雷雨/雪/暴风雪/火山灰/大晴天/雾/沙暴"时：`当前章节天气 == 条件` → 切到对应章节重复刷；否则等下一个整点。
7. 时间条件：`本地时间 ≥ 20:00 或 < 8:00` 才刷"夜晚"物种；`8:00–20:00` 刷"白天"物种（清晨算白天）。洞穴/室内节点不受影响。
8. 季节物种（HABITATS 里带 `spring/summer/autumn/winter` 键的地点，共 4~6 处）：`a.DAYTIME.season().key` 每 3 天变一次，按它决定去不去。
9. 丑丑鱼：每天按巴黎日期轮换到丰缘 114/117/118/119/120 号道路之一（占 1%）——用 `a.Adventure`/`CONFIG.DAILY_SPOTS` 的同一算法（`A(spot, 巴黎日)`）算出今天的道路再去。神奥甜甜蜜树同理（结草儿/三蜜蜂/小卡比兽）。
10. 想刷"本地区还没抓过"的物种 → 吃谜芝果（×3 权重，仅普通道路有效）；想刷"稀有级" → 吃蕉香果（×2）。活动、传说区域、联盟中这两种果无效，别浪费。
11. 合众现象物种（差不多娃娃、电飞鼠、螺钉地鼠、鸭宝宝、保姆曼波）：每个道路步骤只有 5%~10% 有现象，刷"野生节点多"的合众章节；地形要对（草地/洞穴山地/码头/湖海）。

**进化**

12. 每场战斗结束后检查 `S.team` 中 `a.Game.levelEvolution(mon)` 是否非空：游戏会弹窗。多分支（无畏小子、刺尾虫、结草儿）会等待选择 → 脚本需要按目标点选或点「稍后」，否则可能卡住流程（**是否阻塞挂机待确认**）。
13. 定期（例如每 30 分钟）对 PC 执行批量进化：存在 `mon` 满足 `levelEvolution(mon)` 且 `!evoBlocked(mon, to)` → 点「让 N 只宝可梦进化？」。
14. 道具进化：对每只 `itemEvolutions(mon)` 非空且背包 `items[item] > 0` 的宝可梦调用进化；时间进化先判断 `a.DAYTIME.matches(TIME_EVOLUTIONS[to])`（太阳伊布/毒蔷薇/路卡利欧/吉利蛋/结草贵妇在白天，月亮伊布/风铃铃/玛狃拉/天蝎王/绅士蛾在夜晚）。
15. 要做全部伊布进化型等分支 → 先确认家族里保留了足够的个体（家族需要几只会自动保留，或打开「保留重复」），否则后面的分支会因"已拥有"被阻止。
16. 土居忍士：留两只；第一只 Lv20 进化成铁面忍者后背包得到美丽空壳，再对第二只用。
17. 连接线进化不能在单机完成：要么联机交换，要么跳过。

**游走传说**

18. 开始追踪的条件：`adv.badges` 包含对应冠军徽章（城都/丰缘/神奥/合众冠军）且 `S.roam.caught` 不含目标 id。
19. 每次 `a.Roaming.update()` 返回 `[{id, ch, until}]`：若目标 `ch` 与当前章节不同 → 切到 `ch` 章节重开（必定遇到 1 次）；遇到并失败后，如果 `Date.now() < until` 就立刻重开同一章再遇一次（每轮 1 次），否则等它换位置。
20. 背包有大师球时会被自动用在游走传说身上：只想用在某一只上 → 在追其他游走之前把大师球数量考虑进去（游戏不会询问）。
21. 吃苹野果 → 停留时间 ×2（30 分钟），减少切章次数。
22. 城都没有随机大晴天：城都某章出现大晴天 = 炎帝在那里；长时间雷雨/雨同理对应雷公/水君；丰缘的"微风"、合众的"狂风"分别对应拉帝兄妹/龙卷云（艾姆利多无天气信号）。

**传说区域**

23. 只在 `LegendZones.state(zone) == 'open'` 时进入；`shut(id)` 为真（昼夜/月相不符）时进入会被踢出，脚本应改为计算下次开放时间（`whenText()`/`moon()`：满月=8 天周期第 0、1 天，新月=第 4、5 天，巴黎时间减 8 小时）。
24. `state == 'sealed'`：谜题门。雷吉洛克 → 派格斗属性；雷吉斯奇鲁 → 派飞行属性；雷吉艾斯 → 不派、等待（`RIDDLE_WAIT` = 2 分钟，交互细节待确认）；雷吉奇卡斯/凯路迪欧/土地云 → 把指定的三只/两只放进队伍。
25. `state == 'wait'`（代欧奇希斯本周形态已抓）→ 跳过，直到下周。
26. 一次传说挑战平均要 1/0.0118 ≈ 85 轮（金色蔓莓果下约 57 轮），每轮还要先打 4 场野生；优先保证队伍能稳定打赢，再考虑速度。
