# 第二章 剧情章节、道馆与联盟

> 适用版本：`app.3bdd8140e1.js`。本章所有等级、上限、阵容数值都是把游戏自带的 `STORY` 函数（`aceOf / bandOf / routeBand / capOf / levelCap / gymTeam / trainerTeam / staticLevel`）放进 node vm 实际调用后算出来的，不是手抄。标「待确认」的是代码里找到了字段、但没找到（或没读懂）用途的地方。
> 配套数据：`chapters.json`（每章一项，给挂机脚本直接读）。

## 0. 速查：几个贯穿全章的概念

| 概念 | 存档 / 代码 | 含义 |
|---|---|---|
| 章序号 | `adv.chapter`（0 起） | 当前所在章。本攻略所有「第 N 章」都用这个 0 起的序号，与游戏界面左侧显示的编号不一定相同。 |
| 已解锁章 | `adv.unlocked` | 能手动选择的最大章（`p ≤ unlocked` 才能进入）。打完第 S 章时变为 `max(unlocked, S+1)`。**等级上限也按它算，不按当前章算。** |
| 王牌等级 ace | `STORY.aceOf(ch)` | 本章馆主最强那只的等级。章内野生、训练家、上限都围绕它。 |
| 野生等级带 band | `STORY.bandOf(ch)` | 本章野外等级区间 = [上一章 ace, 本章 ace−1]，再平均切给每段路线（`routeBand`）。 |
| 界面「建议 Lv.」 | `chapterMeta(ch).lv` | 本章所有道馆宝可梦的 最低–最高 等级（有 `capMargin` 时最高值取 `capOf`）。 |
| 等级上限 cap | `STORY.capOf(ch)` / `levelCap(adv)` | 宝可梦不会超过此等级，「打败下一位馆主后解除」。 |

### 1.2 地区怎么解锁

相关函数：

- `firstChapterOf(key)`：该地区第一章的序号（关都 0、城都 14、丰缘 31、神奥 48、合众 66）。
- `regionUnlocked(key, adv)` = 该地区有章节 **且** `adv.unlocked ≥ firstChapterOf(key)` **且** `REGIONS[key].open`。
- `regionDone(key)`（代码 `us`）= 该地区**联盟冠军已打败**。
- `regionCleared(key)`（代码 `Mn`）= 该地区**最后一章也已通关**（`unlocked > 最后一章`，或持有最后一章冠军徽章，或最后一章馆主在 `paidLeaders` 里）。
- `opens` 字段：代码 `Ke()` 支持「打完某章后自动开放某地区」，但当前 84 章没有一章写了 `opens`，这条路实际不用。

**能前往下一地区的条件**（函数 `Hs()`）：

1. 当前不处于 `link` 状态（上一次跨区旅行已经「重新连线」）；
2. 下一个地区按 `REGIONS` 顺序紧挨着当前地区，有 `key`、有章节、尚未 `open`、不是 `wip`；
3. **当前地区 `regionCleared`**——也就是**连通关后的章节也要打完**。

各地区「最后一章」：

| 地区 | 冠军章 | 冠军后还有 | 解锁下一地区要打完 | 界面锁定提示 |
|---|---|---|---|---|
| 关都 | 13 联盟冠军（青绿） | 无 | 第 13 章 | 完成关都后解锁 |
| 城都 | 29 联盟冠军（阿渡） | 30 白银山（赤红，Lv100×6） | **第 30 章** | 完成白银山后解锁 |
| 丰缘 | 47 联盟冠军（大吾） | 无 | 第 47 章 | — |
| 神奥 | 64 联盟冠军（竹兰） | 65 严酷山（冥王） | **第 65 章** | 完成严酷山后解锁 |
| 合众 | 82 魁奇思 | 83 巨人洞窟（阿戴克） | 第 83 章（之后没有下一地区） | — |

### 1.3 跨区旅行（`travel` / `link`）

旅行由玩家在界面上手动触发（函数 `ls()`），不会自动发生。

- 非 `aside` 地区：直接 `travel.to` 加入新地区、设 `open=true`、`unlocked` 提到新地区第一章。（目前所有新地区都是 `aside`，这条不会走到。）
- `aside` 地区（城都及以后）：
  - 建立 `link = {from: 旧地区, to: 新地区, side: "to", stash: {旧钱包、道具、队伍…}}`；
  - 新地区从零开始：**金钱清零后发 `START_MONEY` = 3000**、道具重置为 `START_ITEMS`、队伍清空；
  - **`adv.loops` 被清空**；
  - `unlocked` 提到新地区第一章。
  - 游戏内说明：「在新地区，只有在当地捕获的宝可梦能出战，传说区域也一样。原来的地区仍然可以带着它的所有宝可梦游玩。」
  - **新地区的联盟冠军被打败后**（`regionDone(to)`），章节结束时触发 `reconnect()`：旧地区的宝可梦、金钱合并回来（提示「连接已恢复：N 只宝可梦和 X ₽ 回来了！」）。
- `link` 期间等级上限按宝可梦所属地区分别计算（`regionCap(adv, 该宝可梦地区)`），旧地区的宝可梦在旧地区已通关时上限是 100。

### 1.4 在旧地区打工的收入衰减（`BEHIND_MONEY`）

`behindMoney(ch)`：所在章所属地区比「当前最高地区」落后 1 / 2 / ≥3 个地区时，战斗金钱 × **0.75 / 0.6 / 0.5**。另外 `WILD_MONEY = 0`：**野生战不给钱**，钱只来自训练家（`30 × 对方最高等级 × 0.9`）和馆主。

## 2. 章节机制

### 2.1 等级是怎么算出来的

以下公式全部来自 `STORY` 里的函数，已逐章实算，结果见 2.4 的表格。

| 函数 | 实现（意译） |
|---|---|
| `aceOf(ch)` | 章节写了 `ace` 就用它；否则 `region.ace[0] + region.ace[1] × (本地区此前没写 ace 的章数) + aceUp`。 |
| `bandOf(ch)` | 章节写了 `lv` 就用它（白银山、严酷山、巨人洞窟都是 [90,99]）；否则 `[上一章 ace（地区首章用 base+2=2）, 本章 ace − 1]`。 |
| `routeBand(ch, k, n)` | 把 band 平均切成 n 段（n = 本章 route 步数），第 k 段为 `[round(lo + (hi−lo)/n·k), max(下限+1, round(lo + (hi−lo)/n·(k+1)))]`；路线自带 `lv` 时以 `lv` 为准。 |
| 路线训练家 | 等级 = 路线等级 + `TRAINER_LEVEL_BONUS` 随机 0~1，且不超过 `ace + LEVEL_CAP_MARGIN(0)`；队伍只数 = 1 + 随机 0~min(2, ⌊(本章−地区首章)/2⌋+1)，即地区首两章 1–2 只，往后 1–3 只。 |
| `staticLevel(ch, step)` | 定点遭遇：写了 `level` 用它；否则取「它之前最近一段路线的上限 + 2」，且不超过 ace。 |
| `trainerTeam(ch, step)` | 剧情训练家：写了 `scale` 时把队伍按比例缩放，使最高等级 = `staticLevel`；写了 `below` 时再压到 `ace − below` 以下。 |
| `gymTeam(ch, gym)` | 见第 3 节。 |
| `capOf(ch)` | `ace + capMargin`（没写 `capMargin` 时：普通章 +`LEVEL_CAP_MARGIN`=0，联盟章 +`LEAGUE_CAP_MARGIN`=3）；联盟章若不是冠军章且没写 `capMargin`，再与「本联盟最高 ace」取小，即 `min(ace+3, 95)`。 |
| `levelCap(adv)` | 依次看已开放地区：取第一个「还有未打的道馆」的地区，返回 `capOf(第一个 ≥ unlocked、含道馆、且不是已拿到徽章的冠军章)`；所有地区都打完则返回 `max(全部 capOf, LEAGUE_DONE_CAP=100)` = **100**。 |
| 离线限制 | 离线结算时每只宝可梦最多再升 `OFFLINE_MAX_LEVELS` = **12** 级（与上限取小）。 |

**关键点：上限只跟 `unlocked`（推进到的最远章）有关。** 回去刷前面的章节不会降低上限，也不会提高上限。达到上限的宝可梦打赢战斗时经验值记为 0（代码 `capped(mon)` → XP `amount:0`）。

### 2.4 全部 84 章

列说明：
- **野生等级 bandOf**：本章野外等级带，每段路线的细分在 `chapters.json` 的 `route_bands`。冠军章的 bandOf 会出现「95–94」这种下限大于上限的情况，是函数在边界上的原样输出；联盟章的野外步骤被联盟训练家替代，这个值实际用不到。
- **界面推荐**：游戏界面「建议 Lv.」显示的值。
- **等级上限 capOf**：当这一章是你推进到的最远章时的等级上限。
- **推荐攻击属性**：脚本用游戏自带 `TYPE_CHART` 对馆主实际阵容算的（平均倍率 ≥1.25 且对至少一半成员效果绝佳），按平均倍率排序；「—」表示阵容太杂，没有单一属性满足条件。
- ☀️ = 带 `day` 字段；👑 = 冠军（`champion`）；`*` = 阵容随条件变化（按初始宝可梦 / 夜晚），见道馆明细。

## 3. 道馆

### 3.1 一场道馆的流程

章节最后一步通常是 `gym`。进入章节时，带徽章的普通道馆（有 `badge`、非冠军、非联盟章）会在馆主前面插入**道馆训练家**（函数 `O()`，配置 `GYM_TRAINERS`）：

| 项 | 规则 |
|---|---|
| 人数 | 按「本地区到这一章为止第几个有徽章的道馆」：第 1 个 1 人，第 2、3 个 2 人，第 4 个及以后 3 人（`counts:[1,2,2,3]`）。 |
| 等级 | 第 1 人 = 馆主王牌 −4，第 2、3 人 = 王牌 −2（`below:[4,2,2]`）。 |
| 宝可梦 | 本章野外出现的、属性与道馆相同的非传说宝可梦，再加上馆主队伍里的物种，按出现权重抽。 |
| 职业 | `GYM_CLASSES[馆主 sprite]`，例如小刚 → camper、娜姿 → psychic。 |
| 伤害 | 道馆训练家造成的伤害 × `GYM_TRAINERS.damage` = 0.8。 |

`CLASS_TYPES` 是「训练家职业 → 偏好属性」表（如 firebreather→火、swimmer→水、hiker→岩石/地面、guitarist→电），路线上的普通训练家抽职业时会挑一个能从本路线物种池里凑出对应属性队伍的职业（`trainerFor`）。

馆主本人：

- **阵容 `gymTeam(ch, gym)`**：先确定王牌 `A = gym.ace ?? (aceOf(ch) + aceOffset)`，再把原始队伍按比例缩放：每只等级 = `round(原等级 × A / 原队伍最高等级)`。所以**最后一只（或原表里等级最高的那只）一定等于王牌等级**，其余等比例偏低。
- **强度**：馆主宝可梦造成的伤害 × `GYM_DAMAGE × power` = 1.3 × power；HP × `GYM_HP_MULT × power × max(1, 6/队伍只数)^0.7` = 1.3 × power × …（只数越少，单只越肉，比如两只队伍每只 HP ×2.16 再乘其余系数）。`power` 每个馆主不同，见下表。
- **`byStarter`**：合众第 66 章的三曜道馆，馆主随你选的初始宝可梦变化：初始选藤藤蛇 → 伯特（火），暖暖猪 → 寇恩（水），水水獭 → 天桐（草），即总是派出克制你初始的馆主。同章三曜市送的猴子也随初始变化（藤藤蛇→冷水猴、暖暖猪→花椰猴、水水獭→爆香猴，正好克制馆主）。初始判定：看你拥有的宝可梦里哪只（追溯到最初形态）属于 `starter-unova` 的三选一。
- **`atNight`**：夜晚进入时替换字段。第 75 章夏卡（双龙道馆）夜晚换成艾莉丝；第 81 章 N 夜晚把莱希拉姆换成捷克罗姆。
- **`double`**：第 39 章小枫与小南为双打。
- **`champion`**：冠军战（关都青绿、城都阿渡、白银山赤红、丰缘大吾、神奥竹兰、合众魁奇思）。
- `target`：多数劲敌/四天王有 0.25~0.9 的值，用途待确认。

### 3.2 奖金与重打

馆主奖金 = `reward ×（联盟章 ×1.25）×（重打系数）× behindMoney × MONEY_GAIN(0.9) × 金钱加成`。

| 情况 | 重打系数 |
|---|---|
| 第一次打赢（`paidLeaders` 里没有 `章:馆主`，也没有该徽章） | 1 |
| 已拿过徽章或已领过奖金的普通馆主 / 劲敌 | `LEADER_REPLAY_MONEY` = **0.1** |
| 联盟章重打，且该地区联盟还没被打通（`regionDone=false`） | `LEAGUE_TRAINERS.replayMoney` = 0.5 |
| 联盟章重打，地区联盟已打通 | 0.1 |

### 3.3 存档字段

**`adv.badges`**：已获得徽章名（法文原名）数组。

**`adv.paidLeaders`**：`{"章序号:馆主法文名": 1}`。**不是花钱跳过**，而是「这位馆主的首胜全额奖金已经发过了」的记录：每次打赢道馆类战斗（含劲敌、四天王、冠军）都会写入。它还有两个作用：

1. 之后再打这位馆主只给 10% 奖金；
2. **再次输给他时直接放行**（「{馆主}让你通过了：你已经打败过对方了。」），不算失败、不回退；判定条件是持有该徽章或在 `paidLeaders` 里（联盟章除外）。

**`adv.gyms[章][馆主]`**：只记录**第一次打赢之前**的挑战（一旦 `w=1` 或章节已在 `unlocked` 之前，就不再更新）。

| 字段 | 含义 |
|---|---|
| `l` | 打赢之前输了几次 |
| `w` | 是否已打赢（0/1） |
| `lv` | 打赢那一刻出战队伍的平均等级（四舍五入） |
| `t` | 打赢那一刻本章累计用时 `chTime[章]`（毫秒，按 1 倍速换算） |
| `m` | `{物种编号: [赢的次数, 输的次数]}`，按出战队伍里的物种统计 |

**`adv.metLeaders`**：见过的馆主（徽章名或馆主名；联盟章用 `"L"+章序号`），只影响界面上馆主头像是否显示为剪影。

### 4.2 联盟训练家（`LEAGUE_TEAMS` + `LEAGUE_TRAINERS`）

| 项 | 值 |
|---|---|
| 每间人数 | 4 |

### 4.3 推进与失败

- 联盟章里只要不是最后一间，打完就**强制进入下一间**（`S+1`），不受循环影响。
- **在联盟任意一间输了 → 回到第一间**（`leagueOf(ch)[0]`），除非你把整个联盟设成了循环（见 5.2）。联盟章没有「已打败的馆主放行」。
- 联盟章的等级上限 `capOf` = `min(王牌+3, 95)`：83 / 88 / 93 / 95，冠军章 `capMargin=5` → 100。因为 `unlocked` 不会因失败回退，输在第 4 间后回第 1 间重打，上限仍是 95，相当于自动刷级。
- 打完最后一间（冠军）时，若联盟本身不在循环里，结算事件带 `champion:true`。

### 4.4 通关后的变化

1. **等级上限变 100**：`levelCap` 找不到任何还有未打道馆的已开放地区时，返回 `max(所有 capOf, LEAGUE_DONE_CAP=100)` = 100。关都打完冠军、还没去城都时就已经是 100。
2. **冠军章会被反复重打**：打完最后一章后，`next = S+1`，但如果 S+1 属于还没开放的地区（或已经是第 83 章），**就留在本章**——所以打完关都冠军不去城都的话，会一直重打冠军（重打奖金只有 10%）。城都打完冠军会自动进入第 30 章白银山，打完白银山同理会一直重打赤红（Lv100×6）。
3. `regionDone` 为真后可以开启**联盟精英挑战**（`adv.league`，见 4.5），重打联盟训练家的金钱从 ×1.8 降到 ×0.5。
4. 打完该地区最后一章（`regionCleared`）后才能前往下一地区（见 1.2）。

### 4.5 联盟精英挑战（存档 `adv.league`）

这是通关后的独立模式，不是剧情联盟本身：

| 项 | 规则 |

| 开启条件 | `regionDone(地区)` + 地下通道已解锁 + 另一个总开关 `G()`（具体是什么待确认） |

## 5. 章节循环（`loops`）与重玩

### 5.1 怎么设

章节列表每一行右侧的 ↻ 开关（「循环」）切换 `adv.loops` 里的一个键：普通章是章序号（数字），整个联盟是 `"L"`（关都）或 `"L:johto"` 这类字符串，联盟只能整体循环。只有 `≤ unlocked` 的键生效，生效键按章序号排序（联盟按它的第一间排序）。

### 5.2 打完一章后去哪（函数 `ia()` 末尾 + `Te()`）

```
runs++ ; 删除 kept[S] ; unlocked = max(unlocked, min(83, S+1))
若 S 是联盟章且不是最后一间      → 下一章 = S+1
否则若有生效的循环键              → 下一章 = 循环列表里第一个序号 > S 的（S 是联盟章时按联盟第一间比较），没有就回到循环列表第一个
否则若 S+1 存在且其地区已开放     → S+1
否则                              → 留在 S（重打）
```

注意「当前章不在循环里」也照样跳：**只要循环列表非空，打完推进中的新章就会被拉回循环列表**。

### 5.3 循环中失败

```
若当前章（或它所在的联盟）在循环里，且循环列表非空 → 去 Te(当前章)，也就是循环列表里的下一章（当前是最后一个时才回到第一个）
否则 → 重开当前章；联盟章则回到联盟第一间
```

界面提示写的是「输一场就回到第一章」，但代码实际是跳到循环里的**下一章**。只有一个循环章、或输在最后一个循环章时，两种说法结果一样。这一点建议实测确认。

### 5.4 相关存档字段

| 字段 | 含义 |
|---|---|
| `runs` | 打通章节的总次数（每次 `chapterEnd` +1；活动、团体战的每一轮也 +1）。 |
| `kept` | `{章: [馆主…]}`：带 `keep` 标记、本轮已打过的馆主，进章时跳过。**当前没有任何道馆带 `keep`，所以这个字段实际总是空的**；打完一章时会删掉对应的项。 |
| `chTime` | `{章: 毫秒}`：在该章累计的时间，按 1 倍速换算（在线每步 +650ms `STEP_MS`，离线每次行动 +2800ms `ACTION_MS`），不含传说区域、联盟精英挑战、对战塔。界面死亡计数旁显示「按x1速度换算的游戏时间」。 |
| `deaths` | 见第 6 节。 |

### 5.5 用途

- **刷级**：上限只看 `unlocked`，所以最快的刷法是循环**推进中的最新章**（敌人等级最高，经验与敌人等级正相关）。只循环这一章时，打完会重打自己，不会推进；上限已经随 `unlocked` 提到下一章的值。
- **刷钱**：选当前（最新）地区、训练家多的章节；旧地区收入 ×0.75/0.6/0.5；野生战 0 收入；重打馆主只有 10%。
- **刷联盟**：把联盟整体设为循环 `"L…"`，失败时不会回到第一间，而是跳到循环里的下一项。

## 6. 失败机制

在普通章节里输掉任何一场（野生、训练家、道馆都算；函数 `Is()`）：

1. **例外：输给已打败过的馆主**——持有他的徽章，或 `paidLeaders` 里有 `章:馆主`（联盟章不适用）→ 直接放行进入下一步，不算失败。
2. 否则 `deaths[当前章] += 1`（传说区域精英战、联盟精英挑战不计）。
3. 队伍回满，按 5.3 的规则重开本章（或回到联盟第一间、或跳到下一循环章）。章节从第一步重新生成，已领过的一次性礼物/道具不会再出现。
4. 结算消息里的「回到 XX 中心」取的是你输之前经过的最后一个 `heal` 步骤的名字，**只是提示，并不从那里继续**。
5. 第一次打赢之前的道馆失败会记进 `gyms[章][馆主].l` 与 `.m[物种][1]`。
6. 代码里没看到失败扣钱。

`deaths` 与 `chTime` 一起显示在冒险界面的死亡计数面板里（💀 次数 / ⏱️ 用时），只列当前章和有记录的章。

## 7. 对挂机脚本的启示

以下 `ch` 指 `chapters.json` 的条目；`cap(u)` 取 `chapters[g].cap`，g 是 ≥ u 的第一个带 `gym` 且不是已获得冠军徽章的章，地区全部打完则为 100；`team` 指当前出战队伍。

1. **算当前上限**：`cap = cap(adv.unlocked)`。不要用 `adv.chapter` 算：回到旧章刷级时上限仍按最远章计。若 `cap == 100` 且当前地区 `regionCleared`、还有下一地区，说明该去旅行，而不是继续刷。
2. **何时推进下一章**（当前在最新章 `ch = unlocked`，准备打它的道馆）：
   - `min(team.level) ≥ ch.gym.ace` → 直接推进（界面显示绿色「ok」的条件是平均等级 > `ui_lv[1]`）；
   - `avg(team.level) ≥ ch.ui_lv[0]` 且 `gyms[ch][leader].l < 2` → 可以试打；
   - 否则先刷级（见第 3 条）。
3. **何时用循环刷级**：`min(team.level) < cap − 2` 且（`gyms[ch][leader].l ≥ 1` 或 `deaths[ch] ≥ 2`）→ 设 `loops = [unlocked]`（只循环最新章）刷到 `min(team.level) ≥ cap`，然后关掉循环。离线一次最多 +12 级，`cap − min(level) > 12` 时不要指望一晚上刷满。
4. **上限下刷级无意义的判断**：`team.every(m => m.level ≥ cap)` → 再打这一章经验为 0，继续循环只会浪费时间。此时如果还打不过：
   - 大多数章 `cap == ch.gym.ace`（`capMargin=0`），满级也只能和馆主王牌同级，**不能靠等级碾压**，必须换队；
   - 只有地区首章（+2，关都 +4）、第 73 章（+2）、联盟房间（+3，最高到 95）、冠军章（+5）能比王牌高几级。
5. **道馆换队依据**：`ch.gym.counter_types` 是对实际阵容算出的推荐攻击属性。判定 `count(team, m => m.types ∩ counter_types ≠ ∅) ≥ 3` 才算有效；否则从电脑里把属性命中 counter_types 的宝可梦换上。同时 `ch.gym.resist_types` 是能抵抗馆主本系招式的属性，优先挑同时满足「攻击克制 + 防守抵抗」的。阵容会变的章要看 `variants`：第 66 章按初始，第 75、81 章按 `DAYTIME` 是否夜晚。
6. **循环陷阱怎么避免**：推进前检查 `loops.some(k => idx(k) < unlocked)`（`idx("L…")` = 该联盟第一间）。为真时，打完最新章会被拉回旧章。脚本在打最新章的道馆之前要么清空 `loops`，要么只保留 ≥ 最新章的键；并且以每次 `chapterEnd.next` 校验——`next < chapter` 且你本意是推进时，立即关循环并手动选 `unlocked`。
7. **冠军后的原地重打陷阱**：`ch.last_of_region && chapter == ch.ch && next == ch.ch` → 已进入「重打最后一章」状态（奖金 10%）。若 `regionCleared` 且有下一地区 → 触发旅行；没有 → 设循环去刷别的章或转去联盟精英挑战/对战塔。
8. **联盟策略**：联盟里输一次回第一间，所以进第一间前要求 `min(team.level) ≥ 95 − 3`（最后一位四天王王牌 95，联盟房间上限 95）比较稳；或者把联盟设为 `"L…"` 循环，让失败跳到下一项而不是从头来。合众有 6 间（多了 N 和魁奇思），N 的阵容随昼夜变（莱希拉姆/捷克罗姆）。
9. **刷钱**：只在最新地区刷（`behindMoney`：落后 1/2/≥3 个地区收入 ×0.75/0.6/0.5）；选 `ch.trainers` 大的章，野生战不给钱；联盟训练家在 `regionDone` 之前 ×1.8、之后 ×0.5。
10. **跨区前准备**：旅行到新地区会清空 `loops`、队伍清空、钱变成 3000（旧钱暂存，打通新地区联盟后合并回来）。脚本要在旅行后重建队伍（只能用新地区抓到的宝可梦），并重新设置循环。
11. **时段/天气条件**：第 0 章在首次通关前强制白天；带 `day/night/tide` 的步骤时段不符会整段消失，`static` 还要求天气 `skies` 和概率 `chance`。要刷特定遭遇（洛托姆各形态、花岩怪、红色暴鲤龙）时，按 `chapters.json` 里 `specials` 的条件等时机再进章（进章时才展开节点）。

## 附：`chapters.json` 字段

数组下标 = 章序号。每项：

| 字段 | 说明 |
|---|---|
| `ch` / `region` / `region_zh` | 章序号（0 起）、地区 key、地区中文名 |
| `name_zh` / `name_fr` / `path_zh` | 中文章名、法文原名、路线文字 |
| `band` | `bandOf` 的 [下限, 上限] |
| `ui_lv` | 界面「建议 Lv.」的 [低, 高] |
| `ace` / `cap` | `aceOf`、`capOf` |
| `day` | 章节是否带 `day`（仅第 0 章） |
| `steps` | 步骤数（数字）；`kinds` 是逐步的 kind 列表 |
| `wild` / `trainers` | 本章路线野生战、训练家战总数（不含道馆训练家、联盟训练家） |
| `route_bands` | 每段路线的中文名、等级区间、是否仅白天/夜晚、潮汐 |
| `specials` | 礼物/拾取/定点/化石/蛋/关键道具/剧情训练家的中文说明 |
| `gym` | 无道馆为 `null`；否则含 `leader_zh/leader_fr/badge_zh/badge_fr/types[]/ace/champion/double/reward/power/team[[id,中文名,等级]]/counter_types/resist_types/gym_trainers/variants` |
| `league` / `league_room` | 是否联盟章、是联盟第几间 |
| `first_of_region` / `last_of_region` | 是否为地区第一章 / 最后一章 |
